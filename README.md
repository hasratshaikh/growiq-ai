# GrowIQ AI

### Plan. Create. Grow Smarter with AI.

GrowIQ AI is an AI-powered personal growth platform designed to help individuals improve their professional presence, personal brand, social media performance, career direction, and content strategy.

The platform brings multiple AI-powered tools into one workspace, helping users analyze their current position, identify improvement opportunities, and generate personalized strategies for growth.

## Live Demo

🌐 **Live Website:** https://growiqai.netlify.app/

## Project Overview

GrowIQ AI is a Large Language Model (LLM)-powered application that combines AI-driven analysis, personalized recommendations, and structured reports.

The platform is designed around the idea that personal and professional growth should be actionable, measurable, and accessible.

Users can access different AI tools to evaluate their profiles, plan their goals, improve their content, and receive personalized guidance.

## Features

### AI Consultant
An AI-powered personal growth assistant that helps users with career direction, professional presence, personal development, and growth-related questions.

### Instagram Audit
Analyze an Instagram profile and receive AI-generated insights, profile improvement recommendations, and growth priorities.

### LinkedIn Audit
Evaluate a LinkedIn profile and receive recommendations to improve professional positioning, profile presentation, and career visibility.

### Resume Analyzer
Analyze a resume against a target role and job description to identify strengths, missing keywords, and improvement opportunities.

### Content Strategy
Generate a personalized content strategy based on the selected platform, goals, content formats, and duration.

### Goal Planner
Create a personalized roadmap based on career direction, personal goals, background, and growth objectives.

### AI-Generated Reports
View and manage reports generated by different AI tools from the Reports section.

### Dashboard
Access the GrowIQ AI workspace, available AI tools, account information, and growth-related features.

## AI and API Integrations

### OpenRouter

GrowIQ AI uses OpenRouter to connect with large language models for generating personalized insights, analysis, recommendations, and structured reports.

The Instagram Audit implementation uses the model:

`qwen/qwen3.7-flash`

OpenRouter provides the LLM interface used for AI-powered report generation.

### SocialCrawl

SocialCrawl is integrated into the Instagram Audit workflow to retrieve Instagram profile and related public profile data.

The collected data can be used as context for AI-powered profile analysis and recommendations.

### Supabase

Supabase provides backend infrastructure for the application, including:

- User authentication
- Database operations
- Report storage
- Supabase Edge Functions
- Backend API functionality

## How It Works

1. User opens GrowIQ AI and selects an AI tool.
2. User provides the required profile, career, resume, or goal-related information.
3. The frontend sends the request to the appropriate backend service.
4. Supabase Edge Functions process supported backend workflows.
5. External APIs and LLM services are used where required.
6. AI-generated insights and recommendations are returned.
7. Reports can be stored and accessed through the Reports section.

## Getting Started

### Prerequisites

Before running the project locally, make sure you have:

- Node.js
- npm
- Supabase account
- OpenRouter API key
- SocialCrawl API key for Instagram Audit functionality

### Installation

Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Navigate to the project directory:

```bash
cd growiq-ai
```

Install root dependencies:

```bash
npm install
```

Navigate to the frontend:

```bash
cd frontend
```

Install frontend dependencies:

```bash
npm install
```

### Environment Variables

Create a `.env` file inside the `frontend` directory and configure the Supabase environment variables required by your frontend implementation.

For Supabase Edge Functions, configure the required secrets through Supabase.

Never commit API keys, access tokens, or private credentials to GitHub.

### Run the Frontend

From the frontend directory:

```bash
npm run dev
```

Vite will start the local development server. Open the URL displayed in the terminal.

## Supabase Edge Functions

The backend contains Supabase Edge Functions for the following AI tools:

- AI Consultant
- Content Strategy
- Goal Planner
- Instagram Audit
- LinkedIn Audit
- Resume Analyzer

Each function is responsible for processing the corresponding backend workflow.

## Deployment

### Frontend Deployment

The frontend is deployed on Netlify.

Live URL:

https://growiqai.netlify.app/

To deploy your own instance:

1. Connect your GitHub repository to Netlify.
2. Configure the frontend build settings.
3. Add the required frontend environment variables.
4. Deploy the application.

### Backend Deployment

Supabase Edge Functions can be deployed using the Supabase CLI.

Example:

```bash
supabase login
supabase link --project-ref YOUR_SUPABASE_PROJECT_REF
supabase functions deploy instagram-audit
```

Repeat the deployment command for the other Edge Functions as required.

## Security and Privacy

GrowIQ AI uses Supabase for backend services and authentication.

Important security practices:

- Keep API keys and secrets on the server side.
- Do not expose private API credentials in frontend code.
- Use Supabase Row Level Security where applicable.
- Validate user input on the backend.
- Restrict access to user-specific reports.
- Review external API data-sharing requirements.

When users submit information to AI-powered tools, relevant data may be processed by external services such as OpenRouter or SocialCrawl depending on the selected feature.
